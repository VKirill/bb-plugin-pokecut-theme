# Тема Pokecut для BB

Мягкая «дашбордная» тема для BB по мотивам админки
[Pokecut](https://pokecut.rakibulism.space): серая оболочка, область контента
как одна приподнятая скруглённая панель с тонкой рамкой и мягкой тенью, белые
карточки, открытый тред выделен приподнятой «таблеткой», кнопка отправки
с розово-фиолетовым градиентом. Светлый и тёмный режимы.

На скриншотах демонстрационные данные.

Повторён только визуальный язык: исходники, картинки и шрифты Pokecut не
включены, Inter в BB уже есть.

Также тема переоформляет сам чат: поле ввода, пузыри сообщений, код, строки
работы, линии дерева, пиксельные загрузчики, карточки подтверждений, общая
подсказка. Эта часть перенесена из [Beautiful Chat](https://github.com/diip3sh/bb-plugin-beautiful-chat)
(MIT) и перекрашена в токены Pokecut; Beautiful Chat держите выключенным.
Настройки — «Настройки → Плагины → Pokecut Theme → Оформление чата», на русском
или английском.

## Установка

```sh
bb plugin install https://github.com/VKirill/bb-plugin-pokecut-theme
bb theme set plugin:pokecut-theme:pokecut
```

Или выберите **Pokecut** в «Настройки → Оформление». Тема следует режиму
светлый/тёмный BB.

Вернуть как было: `bb theme reset` или выбрать другую тему. Удаление плагина
убирает тему; файлы BB не меняются.

Подробности о палитре и селекторах — в [README.md](README.md).
